# Data Dictionary & Dataset Specifications

This document provides schema definitions, descriptions, data types, and creation scripts for all production datasets in `data/processed/`.

---

## Field Schemas for New Modules

### 1. `satellite_context.csv`
- **Creator Module:** `src/satellite/inference.py`
- **Script:** `scripts/run_satellite_inference.py`

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `cluster_id` | `int64` | Cluster integer ID. |
| `satellite_image_available` | `boolean` | `True` if clear Sentinel-2 image retrieved; `False` if obscured or unavailable. |
| `predicted_landcover_class` | `string` | Top EuroSAT class prediction (`Industrial`, `Forest`, `AnnualCrop`, etc.). |
| `prediction_confidence` | `float64` | Visual similarity confidence (`0.0` to `1.0`). Note: **MODEL CONFIDENCE**, NOT probability of fire. |
| `image_date` | `string` | Date of retrieved Sentinel-2 scene. |
| `cloud_cover` | `float64` | Cloud cover percentage ($0\text{--}100\%$). |
| `observation_status` | `string` | Diagnostic text status. |

---

### 2. `emergency_alerts.csv`
- **Creator Module:** `src/response/alert_engine.py`
- **Script:** `scripts/generate_alerts.py`

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `cluster_id` | `int64` | Cluster integer ID. |
| `risk_score` | `float64` | Risk Index score ($0\text{--}100$). |
| `risk_level` | `string` | Risk level (`LOW`, `MEDIUM`, `HIGH`). |
| `false_alarm_indicator` | `string` | False alarm concern level. |
| `classification_label` | `string` | Multi-source context label. |
| `alert_priority` | `string` | Priority classification (`HIGH PRIORITY ALERT`, `REVIEW / VERIFICATION`, `MONITOR / REVIEW`, `NO ALERT`). |
| `recommended_action` | `string` | Action recommendation text. |
| `nearest_station_name` | `string` | Name of closest regional fire command station. |
| `station_distance_km` | `float64` | Geodesic distance to fire station (km). |
| `alert_rationale` | `string` | Explanation of alert recommendation rationale. |
