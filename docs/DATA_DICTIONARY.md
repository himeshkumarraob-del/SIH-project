# Data Dictionary & Dataset Specifications

This document provides schema definitions, descriptions, data types, and creation scripts for all production datasets in `data/processed/`.

---

## Production Dataset Overview

All datasets in `data/processed/` are deterministically generated by the pipeline scripts.

| Dataset File | Rows | Primary Key | Creator Script | Description |
| :--- | :---: | :---: | :--- | :--- |
| `firms_india.csv` | 4,524 | `detection_id` | `scripts/filter_india_boundary.py` | Cleaned point detections clipped to India WGS84 boundary. |
| `firms_persistence.csv` | 1,792 | `cluster_id` | `scripts/analyze_persistence.py` | Spatio-temporal cluster summary records. |
| `firms_features.csv` | 1,792 | `cluster_id` | `scripts/build_features.py` | 24 extracted numerical feature vectors per cluster. |
| `firms_anomalies.csv` | 1,792 | `cluster_id` | `scripts/run_anomaly_detection.py` | Isolation Forest anomaly scores, flags, & levels. |
| `firms_ai_results.csv` | 1,792 | `cluster_id` | `scripts/explain_anomalies.py` | Explainable AI characterizations & explanations. |
| `firms_false_alarm.csv` | 1,792 | `cluster_id` | `scripts/analyze_false_alarms.py` | False alarm concern indicators & evidence reliability ratings. |
| `firms_risk_results.csv` | 1,792 | `cluster_id` | `scripts/calculate_risk.py` | Risk Intelligence Index (0–100) scores & factors. |
| `gis_thermal_events.csv` | 4,524 | `detection_id` | `scripts/build_gis_map.py` | Master GIS point detections joined with cluster AI results. |
| `thermal_movement.csv` | 1,792 | `cluster_id` | `scripts/analyze_thermal_movement.py` | Centroid displacement, initial bearing, direction, & rates. |

## Field Schemas for New Intelligence Modules

### 1. `data/processed/firms_false_alarm.csv`
- **Creator Module:** `src/models/false_alarm_detector.py`
- **Script:** `scripts/analyze_false_alarms.py`

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `cluster_id` | `int64` | Cluster integer ID. |
| `false_alarm_indicator` | `string` | False alarm concern level (`LOW`, `MEDIUM`, `HIGH`). Note: `HIGH` indicates weak supporting evidence. |
| `detection_reliability` | `string` | Evidence rating (`HIGH`, `MEDIUM`, `LOW`). |
| `false_alarm_reasons` | `string` | Semi-colon separated text explaining evidence factors (e.g. `single point observation; no temporal recurrence`). |

---

### 2. `data/processed/firms_risk_results.csv`
- **Creator Module:** `src/models/risk_intelligence.py`
- **Script:** `scripts/calculate_risk.py`

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `cluster_id` | `int64` | Cluster integer ID. |
| `risk_score` | `float64` | Experimental risk index (`0.0` to `100.0`). |
| `risk_level` | `string` | Risk classification (`LOW`, `MEDIUM`, `HIGH`). |
| `risk_factors` | `string` | Semi-colon separated list of strongest risk drivers. |
| `risk_explanation` | `string` | Human-readable explanation sentence summarizing risk rationale. |

---

### 3. `data/processed/thermal_movement.csv`
- **Creator Module:** `src/gis/thermal_movement.py`
- **Script:** `scripts/analyze_thermal_movement.py`

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `cluster_id` | `int64` | Cluster integer ID. |
| `observation_count` | `int64` | Total detections in cluster. |
| `active_days` | `int64` | Number of distinct active dates. |
| `first_detection` | `string` | Earliest ISO timestamp in cluster. |
| `last_detection` | `string` | Latest ISO timestamp in cluster. |
| `time_span_days` | `float64` | Span in days between earliest and latest detection. |
| `start_latitude` | `float64` | Daily centroid latitude on earliest date. |
| `start_longitude` | `float64` | Daily centroid longitude on earliest date. |
| `end_latitude` | `float64` | Daily centroid latitude on latest date. |
| `end_longitude` | `float64` | Daily centroid longitude on latest date. |
| `total_movement_distance_km` | `float64` | Haversine displacement distance (km). |
| `movement_rate_km_per_day` | `float64` | Movement rate ($\text{dist} / \text{days}$). |
| `movement_bearing_degrees` | `float64` | Initial compass bearing ($0^\circ - 360^\circ$). |
| `movement_direction` | `string` | 8-way compass direction (`N`, `NE`, `E`, `SE`, `S`, `SW`, `W`, `NW`, `STATIONARY`, `INSUFFICIENT_DATA`). |
| `movement_confidence` | `string` | Rating (`HIGH`, `MEDIUM`, `LOW`, `INSUFFICIENT_DATA`). |
| `movement_status` | `string` | Status (`MOVING`, `STATIONARY`, `INSUFFICIENT_DATA`). |
